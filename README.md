# Фид Авито Оксаны Кожевниковой

Этот репозиторий предназначен только для аккаунта Авито Оксаны Кожевниковой (`9523215`).

- Публичный XML: `https://margobatagova28-glitch.github.io/oksana-avito-feed/feed.xml`
- Фотографии: `https://margobatagova28-glitch.github.io/oksana-avito-feed/photos/`
- Все идентификаторы объявлений начинаются с `oksana-`.

Перед публикацией обязательно запускать `scripts/assert_oksana_feed_boundary.ps1 -Online` из рабочего проекта Оксаны. Проверка останавливает публикацию, если API отвечает от другого аккаунта или в фиде встречаются чужие ID, ссылки или маркеры.
